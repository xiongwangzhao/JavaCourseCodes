# 履约域图二：业务场景包能力矩阵

## 1. 文档说明

本文用于描述履约域中各一级业务场景包在模块中的专属能力。

说明：

- 图二只描述**业务场景扩展能力**
- 图一中已存在的内核标准能力，不在本文重复
- 当前一级业务场景收敛为：
  - `仓配快递`
  - `即时配送`
  - `门店自提`
- 场景能力最终只回写到本系统的 `履约单`

---

## 3. 设计结论

当前履约域一级业务场景包收敛为：

1. `仓配快递场景包`
2. `即时配送场景包`
3. `门店自提场景包`

设计原则：

- 图二只承载业务场景专属能力
- 场景能力仅影响本系统 `履约单` 的状态、进度和外部引用信息
- 不把下游发货单、配送单纳入本系统主模型
