## 1. 文档说明

本文用于沉淀支付回调模块中首批建议开放的：

- 内核标准能力选配
- 内核标准能力扩展点
- 业务场景扩展能力选配

说明：

- 这里只描述内核应暴露的能力接口
- 不关心具体业务线插件包实现
- 不是所有能力都开放；本表仅保留首批核心开放能力

## 3. 首批开放策略总结

### 3.1 内核标准能力

首批建议重点开放以下内核能力：

- 回调报文解析Ability
- 支付单匹配Ability
- 支付快照装载Ability
- 业务场景识别Ability
- 签名校验Ability
- 金额校验Ability
- 状态流转校验Ability
- 支付结果标准化Ability
- 支付单结果落账Ability
- 后置事件生成Ability
- 失败补偿触发Ability
- 回调响应生成Ability

### 3.2 业务场景扩展能力

首批建议按以下策略开放：

| 业务场景包 | 首批策略 |
| --- | --- |
| 组合支付 | 扩展点优先 |
| 分期支付 | 少量选配 + 扩展点 |
| 国补支付 | 扩展点优先 |
| 货到付款 | 路径型选配 + 扩展点 |
| 定金支付 | 扩展点优先 |
| 尾款支付 | 扩展点优先 |
| 0元支付 | 路径型选配 + 扩展点 |

### 3.3 首批不建议开放的方向

以下方向建议后续再逐步开放：

- 回调展示类能力
- 文案提示类能力
- 回调结果组装细节
- 过细粒度的状态机分支
- 过细粒度的补偿策略拆分
