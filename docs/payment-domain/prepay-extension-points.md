# 预支付模块-能力扩展表

## 1. 文档说明

本文用于沉淀预支付模块中首批建议开放的：

- 内核标准能力选配
- 内核标准能力扩展点
- 业务场景扩展能力选配
- 业务场景扩展能力扩展点

说明：

- 这里只描述内核应暴露的能力接口
- 不关心具体业务线插件包实现
- 不是所有能力都开放；本表仅保留首批核心开放能力

## 3. 首批开放策略总结

### 3.1 内核标准能力

首批建议重点开放以下内核能力：

- 支付对象装载Ability
- 支付主体装载Ability
- 终端上下文装载Ability
- 业务场景识别Ability
- 渠道规则装载Ability
- 支付时效装载Ability
- 渠道能力装载Ability
- 渠道路由决策Ability
- 渠道请求构建Ability
- 预支付结果标准化Ability
- 支付单结果回写Ability
- 支付提交快照生成Ability
- 拉起参数生成Ability
- 预支付响应组装Ability

### 3.2 业务场景扩展能力

首批建议按以下策略开放：

| 业务场景包 | 首批策略 |
| --- | --- |
| 组合支付 | 少量选配 + 扩展点 |
| 分期支付 | 少量选配 + 扩展点 |
| 国补支付 | 以扩展点为主，仅保留极少量路径型选配 |
| 货到付款 | 路径型选配 + 扩展点 |
| 定金支付 | 以扩展点为主，保留少量支付单模板选配 |
| 尾款支付 | 以扩展点为主，保留少量支付单模板选配 |
| 0元支付 | 路径型选配 + 扩展点 |
